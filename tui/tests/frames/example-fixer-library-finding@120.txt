One query, many faces
The filter bar is a query editor: the attribute row, the metadata columns, the chips and the rules all read and write
the text of one query, so a beginner can click and an expert can type, and both see the other's form. Built (CAT-04,
CAT-19); the rule form is in the engine, its panel is planned.

The language, as built
Fields                                Written                                  What it does
Free text                             tram night                               Name, folder, keywords, title, caption, …
rating, flag, label                   rating>=3  -flag:reject  label:red,blue  Comparisons, negation, lists
kw                                    kw:Birds  kw:"Places/Portugal"           A parent matches its children; synonyms …
date                                  date:2024-06..2024-08  date:last:30d     Ranges and relative dates
camera, lens, iso, f, focal, shutter  lens:35  iso<=800  f:1.4..2.8            Substrings, numbers, ranges
folder, name, type, has               in:"Trips/2024"  type:raw  has:gps       Where it is, what it is, what it has
missing, offline, edited              offline:yes  edited:no                   States, from the index
Groups                                (camera:Z6 OR camera:X-T5) -kw:Test      AND by default, OR, -, parentheses

How it grows
A field added to the grammar is at once searchable, completable, savable in smart collections and presets, runnable from
⌘K and scriptable from the command line. Counting it in a metadata column also needs a column in the index's column
store. What's arriving:
